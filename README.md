# Modelo de Lista de Tarefas

Aplicação web de uma lista de tarefas desenvolvida em Next.js, com foco na organização, exibição e cadastro de conteúdos utilizando armazenamento local.

## Funcionalidades

- Exibir lista de tarefas;
- Cadastro de novas tarefas;
- Tarefas podem ser marcadas como concluídas ou excluídas;
- Exibe um contador com o número de tarefas;
- Dados salvos em localStorage.

## Tecnologias utilizadas

- Next.js
- React
- TypeScript
- HTML5
- CSS3
- Jest
- React Testing Library (@testing-library/react)
- @testing-library/user-event

## Como utilizar

1. Clone o repositório;
2. Acesse a pasta do projeto:

```bash
cd blog-opiniao
```

3. Instale as dependências:

```bash
npm install
```

4. Execute o projeto:

```bash
npm run dev
```

5. Para executar os testes:

```bash
npm test
```
